# Excel Projects Portfolio

This repository contains Excel-based projects focused on sales analysis, reporting, automation, and inventory management using advanced Excel features.

## Projects Included

### 1. Sales Dashboard
- Built an interactive dashboard to track sales performance
- Analyzed sales trends by time period and product/category
- Used Pivot Tables, Pivot Charts, Slicers, and Conditional Formatting
- Helped identify top-performing and low-performing products

### 2. MIS Report Sheet
- Created a Management Information System (MIS) report for management review
- Summarized key business metrics in a structured format
- Used IF formulas, VLOOKUP/XLOOKUP, Pivot Tables, and Conditional Formatting
- Improved reporting accuracy and reduced manual effort

### 3. Inventory Management System
- Designed an inventory tracking system to monitor stock levels
- Identified low-stock, overstocked, and fast-moving items
- Used SUMIFS, IF formulas, Pivot Tables, and inventory logic
- Supported better inventory planning and control

### 4. Automated Sales Report
- Developed an automated sales reporting system
- Reports update automatically when new data is added
- Used Pivot Tables, dynamic ranges, formulas, and charts
- Reduced manual reporting time and improved efficiency

## Tools & Skills Used
- Microsoft Excel
- Pivot Tables & Dashboards
- Advanced Excel Formulas
- Data Analysis & Reporting
- Sales and Inventory Analysis
